Что завершили с прошлого отчёта

Повторно проверили CORE и исправили вывод команд

Команды step и run теперь показывают раннюю остановку без сбоя и правильно подписывают исторический режим LEAN. Локальная приёмка на Windows охватила 500 тестов, 12 этапов CORE, семь сравнений LEAN по AIG, AAPL и IBM и два сценария поиска. Обычный офлайн-запуск AIG и его точный повтор вернули одинаковый результат.

В новой приёмке маршрут Codex проверяли с тестовой заменой процесса. Запуск с двумя реальными обращениями к Codex относится к предыдущей сборке. Изменения CORE · Ранее проверенные результаты.

Опубликовали сборщик и проверку времени получения новостей

При обработке сохранённых новостей сборщик отклоняет записи с некорректным временем получения или временем вне UTC. Проверки сборщика на GitHub прошли на Windows и Ubuntu. Изменения сборщика · Результаты проверок.

Объединили изменения и синхронизировали рабочую копию

Оба набора изменений прошли CI перед слиянием. Проверки объединённой ветки на Windows и Ubuntu также прошли. Основная ветка на GitHub и локальная рабочая копия совпали по коммиту f88de8e. После синхронизации локальная сборка CORE совпала с принятой версией, а сохранённый запуск AIG остался в состоянии STOPPED с причиной MODEL_STOP. Проверки CORE до слияния · Проверки объединённой ветки.

Вопросы для обсуждения

В списке семь вопросов из разбора трейдерских материалов. Вот три, которые уже подробно разбирали. Тема пока открыта.

  • Добавляет ли разница между объёмом рыночных покупок и продаж полезную информацию к данным о цене, волатильности и ликвидности?
  • Помогает ли сочетание заранее заданного диапазона цен и сигнала по сделкам лучше, чем каждый из них по отдельности?
  • Помогают ли принудительные закрытия позиций сократить потери лучше, чем обычное правило снижения позиции при росте волатильности?

Полнота данных из трейдерских материалов

В нескольких идеях формулы индикаторов и правила разметки описаны лишь частично. Для данных о принудительных закрытиях позиций пока не подтверждено, какой исторический поток использовал автор и какие записи в нём доступны.

Что ещё требует подтверждения

Тема, данные и критерий успеха

Рыночный вопрос пока не выбран. Для выбранного вопроса предстоит проверить ближайшие аналоги и небольшой образец данных, затем согласовать базу сравнения, издержки, метрику и критерий успеха. Подтверждённого рыночного эффекта пока нет.

Бюджет обращений к модели

Для контрольных запусков известны число обращений и время ожидания. Фактическая стоимость и остаток лимита подписки по этим записям не подтверждены. Бюджет для исследования ещё предстоит согласовать.
