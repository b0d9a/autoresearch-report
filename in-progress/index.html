Выбор вопроса

В списке семь вопросов из разбора трейдерских материалов, отдельно есть черновики по новостям. Например, можно обсудить, помогает ли информация о принудительных закрытиях позиций лучше управлять риском, чем обычная оценка волатильности. Тема ещё не выбрана.

Полнота данных из трейдерских материалов

В нескольких идеях формулы индикаторов и правила разметки описаны лишь частично. Для данных о принудительных закрытиях позиций пока не подтверждено, какой исторический поток использовал автор и какие записи в нём доступны.

Дата, на которую можно опираться в новостях

Октябрьская запись в ленте ФРС вела на исправленный текст, который сборщик получил 4 ноября. Чтобы использовать такой текст в исторической проверке, нужна версия, действительно доступная на тот момент.

Проверки сборщика после публикации

Для сборщика настроен отдельный запуск проверок на Windows и Ubuntu. По последнему изменению есть результат локального прогона Windows. Результат запуска на GitHub в записи задачи пока не подтверждён.
