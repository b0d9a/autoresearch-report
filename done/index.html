После переключения службы проверили вход для обеих заранее созданных учётных записей. Каждая открыла закрытую ленту в отдельном сеансе. Самостоятельная регистрация недоступна. Статус приёмки.

Фоновый сбор материалов и сводка на русском

В разделе «Новости» появились краткие пересказы на русском. Через меню заголовка можно перейти к оригиналу, а для поддерживаемых статей — открыть черновики гипотез в отдельной вкладке. Новый набор черновиков создаётся по явному действию пользователя. Проверка сводки и меню.

Он завершился по решению модели. На отдельном прогоне CORE подтвердил остановку после первого проверенного шага. Как проверили запуск и остановку.

Расчёты и обратная связь

Приёмка расчётного ядра CORE на Windows

Для принятой сборки прошли 500 тестов, 12 этапов проверки CORE, семь контрольных сравнений LEAN по AIG, AAPL и IBM и два сценария поиска. LEAN воспроизводит сделки на исторических данных. Например, в одном сценарии AIG расчёт дал 999,68 доллара против 1 000 долларов в варианте без сделок. Маршрут Codex в этой сборке проверили с тестовой заменой процесса. Подробности приёмки.

Восстановление после сбоя

В трёх сценариях после принудительной остановки система подхватила уже проверенный результат стратегии. Если контрольная часть была повреждена, отчёт не появлялся. На принятой сборке семь точных повторов вернули прежние результаты без дубликатов.

Реальные обращения к Codex в отдельном прогоне

На предыдущей принятой сборке первый вызов Codex предложил вариант для сценария AIG. Второй получил два уже сверенных результата и остановил поиск. Ранее этот цикл проверили на учебных данных.

Поиск продолжился с сохранённого места

В отдельной проверке процесс остановили после сохранения отчёта AIG. При повторе система использовала прежний ответ Codex и прежний расчёт LEAN, записав обратную связь один раз.

Отдельный доступ к итоговой проверке

На учебном примере проверили, что поиск и итоговый запуск работают с разными правами. В проверенной Linux-среде поиск не мог читать закрытые файлы итоговой проверки.

Пакет свидетельств для принятой сборки

В чистой копии проекта сверили 16 файлов пакета и подтвердили совпадение исходников с принятой сборкой CORE. В пакет вошли выдержки из шести сохранённых отчётов. Изменения в документации и пакете пока оформлены как черновик в закрытом репозитории. Состав пакета и пределы проверки.
