Отчёт по Autoresearch

Autoresearch собирает материалы для торговых гипотез и показывает в браузере, какие проверки нужны каждой идее. Сохранённые прогоны CORE можно открыть и сверить по шагам.

Готово Лента автоматически собирает новости, Telegram и RSS. На 120 записях первого проверенного сбора кнопка генерации создала шесть черновиков гипотез. У каждого черновика есть интерактивная схема проверки. Запуск и остановку офлайн-прогонов CORE проверили в браузере. В работе Подготовили комплект для закрытого запуска на Linux с доступом через SSH и проверили его локально. Открыты проверка на целевом сервере и выбор первой гипотезы для исследования. Планы Проверить закрытый доступ и обновление ленты на сервере. Для выбранной гипотезы проверить прошлые работы и данные, затем согласовать сравнение и условия прогона.

Проверки подтвердили работу интерфейса и расчётного контура на контрольных сценариях. Рыночный эффект ещё предстоит проверить после согласования темы и правил эксперимента.
